# iVouch Lite Demo

## What it proves

- Signup, login, upload, result card, and review flow work locally.

## What it does not prove

- Zero-shot labels are demo-grade, not accurate.
- Safety screening is a mock list, not real screening.
- No forensic detector, no launch or pilot claim.

## Run

- Install, seed a reviewer, start the server, upload once.
- Full run steps land with the spec 4 brief.
